# Contribute

## Feedback

If you have identified a problem with this knowledgebase or have a request for
new information to be added, you can create a new issue
[here](https://github.com/molecularprogrammer/knowledge-base/issues).

To avoid duplicates, please search the existing issues before creating a new one.

## Casual Contributors

If you are not familiar with Git or Github, but would like to make a small contribution, please
follow the steps in the [Feedback section](#feedback), then paste your addition into the issue.

## Developer Contributors

If you would like to make any changes, please follow the steps in the
[Feedback section](#feedback), to create or identify an existing issue.

Please use inline links and/or [mkdocs
footnotes](https://squidfunk.github.io/mkdocs-material/reference/footnotes/) for citing sources.
This is especially true for any information that has not been verified through some form of testing
or experimentation by this project's maintainers.

Please use [mkdocs admonitions](https://squidfunk.github.io/mkdocs-material/reference/admonitions/)
to call out any content that requires further attention.

[Please link the pull request back to the issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue#linking-a-pull-request-to-an-issue-using-a-keyword).

## Maintainers

Help reviewing and merging pull requests is appreciated.

Trusted, frequent contributors will be granted elevated priviledges to do this.

## Automated Contributions

To automate the process of identifying new content, a tool will be setup with a list of sources to
periodically scan, compare against known information, and summarize for further review. The project
for this tool can be found [here](https://github.com/molecularprogrammer/content-collector-agent).
Note that this is just the source code; access to the deployed version is not shared, since it is
not free to run, and there is currently no funding for this knowledgebase.
